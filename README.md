# Hotel Booking Analysis | Excel, MySQL & Power BI

## Project Overview
Developed an end-to-end Hotel Booking Analysis project to analyze booking trends, cancellation patterns, customer behavior, and hotel performance using Excel, MySQL, and Power BI.

## Tools & Technologies
- **Excel:** Data cleaning, validation, and exploratory analysis
- **MySQL:** Data analysis using SQL queries
- **Power BI:** Data modeling, DAX measures, and interactive dashboards

## Key Performance Indicators
- **Total Bookings:** 119,390
- **Cancelled Bookings:** 44,224
- **Cancellation Rate:** 37.04%
- **Total Guests:** 234,988
- **Average Stay Duration:** 3.43 nights
- **Repeat Guest Percentage:** 3.19%

## Key Insights
- City Hotels experienced higher cancellation rates than Resort Hotels.
- Bookings made more than 180 days in advance had a 57.01% cancellation rate.
- Online Travel Agencies contributed the largest share of bookings.
- August recorded the highest booking volume.
- Repeat guests accounted for only 3.19% of bookings.

## Dashboard
Created interactive Power BI dashboards covering booking performance, cancellation analysis, customer behavior, and market trends.
